Overview of Morse Code
Morse code is a method of communication that uses dots (.) and dashes (-) to represent letters, numbers, and punctuation.
History of Morse Code
Morse code was developed by Samuel Morse and Alfred Vail in the 1830s–1840s. It was used with the telegraph to send messages over long distances.

The first message sent in 1844 was:
"WHAT HATH GOD WROUGHT"

How Morse Code Works
- Dot (.) = short signal
- Dash (-) = long signal

Timing:
- Dot = 1 unit
- Dash = 3 units
- Space between letters = 3 units
- Space between words = 7 units
